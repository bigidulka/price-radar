# Price Radar

Мониторинг цен конкурентов и репрайсер для продавцов на маркетплейсах: **Telegram-бот**,
**веб-дашборд** и **Excel-отчёт** поверх одного ядра.

**Демо:** https://bigidulka.github.io/price-radar/ — каталог автозапчастей на синтетическом рынке
(цены и продавцы сгенерированы, чтобы показать работу правил).

## Зачем

Продавец автозапчастей на Ozon и Wildberries конкурирует за одни и те же OEM-номера с десятками
магазинов. Цены у конкурентов меняются несколько раз в день, а вручную следить за ними и
пересчитывать маржу с учётом комиссии площадки невозможно. Price Radar:

- раз в N минут снимает цены с карточек конкурентов (Ozon, Wildberries);
- для каждого товара считает рекомендуемую цену и **объясняет решение словами**;
- никогда не опускает цену ниже минимума: себестоимость + целевая маржа + комиссия площадки;
- присылает в Telegram только то, что требует внимания, и применяет цену в один клик;
- отдаёт дашборд, JSON API и Excel для бухгалтерии и закупок.

## Правила репрайсинга

| Ситуация | Действие |
|---|---|
| Есть конкуренты в наличии | встаём на шаг ниже самого дешёвого (₽ или %), округляем до 10 ₽ |
| Лидер ниже нашего минимума | **не демпингуем**, держим минимальную цену |
| Мы дешевле всех с запасом | поднимаем до шага ниже лидера, не выше РРЦ |
| У всех конкурентов нет в наличии | поднимаем на `raise_pct`, не выше РРЦ |
| Изменение меньше `min_change` | ничего не делаем, чтобы цена не «дёргалась» |

Минимальная цена считается так: `cost × (1 + margin) / (1 − commission)`. Все пороги задаются в
`Strategy` и в карточке товара.

## Архитектура

```
providers/            Ozon (через ozon-client, браузерная сессия) · Wildberries (card API) · demo
   │  fetch(url) → Offer
service.Radar ────────► storage (SQLite: товары, ссылки, история цен, журнал изменений)
   │  refresh(): параллельный опрос, падение одного источника не ломает прогон
repricer.decide() ────► Decision(action, proposed, margin, reason)
   │
   ├── bot.py   aiogram 3: /add /track /list /check /apply /export, фоновые уведомления
   ├── web.py   FastAPI: дашборд, /api/products, /api/refresh, /export.xlsx
   └── cli.py   serve · bot · refresh · demo-site
```

- **Идемпотентность**: одно наблюдение (ссылка + время) сохраняется один раз, повторный прогон не плодит дубли.
- **Отказоустойчивость**: ошибки площадок (антибот, снятая карточка) попадают в отчёт, решение
  принимается по последним известным ценам.
- **Доступ**: бот работает только для `PRICE_RADAR_ADMINS` — он меняет цены.

## Запуск

```bash
python -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/pytest                       # 20 тестов, без сети

.venv/bin/price-radar serve --demo     # дашборд на синтетических данных: http://127.0.0.1:8000
.venv/bin/price-radar demo-site docs   # статическая версия для GitHub Pages

cp .env.example .env                   # TELEGRAM_BOT_TOKEN, PRICE_RADAR_ADMINS, PRICE_RADAR_PROXY
.venv/bin/price-radar bot              # Telegram-бот
.venv/bin/price-radar refresh --apply  # один цикл из cron
```

Ozon подключается extra-зависимостью: `pip install -e '.[ozon]'` (нужен Chrome с CDP, см.
[ozon-client](https://github.com/bigidulka/ozon-client)).

## Ограничения

Ozon и Wildberries закрывают публичные страницы антиботом и ограничивают доступ по региону, поэтому
для рабочего режима нужен региональный выход (`PRICE_RADAR_PROXY`) и умеренная частота опроса.
Для своих товаров надёжнее официальные Seller API; конкурентов они не показывают — для этого и
нужен мониторинг публичных карточек.
